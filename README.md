# Шахматный наставник

Android-приложение: персональный шахматный тренер, подключённый к аккаунту Lichess.
Разбирает партии и объясняет по-русски, **почему** тот или иной ход лучше.

## Что это умеет (план)

- Разбор любой прошлой партии из аккаунта Lichess
- Автоматический поиск своих ошибок по всей партии
- Подсказки в реальном времени — **только** в партиях против компьютера Lichess

## Фейр-плей

Подсказки в живых партиях против людей не поддерживаются и не будут. Lichess прямо
запрещает внешнюю помощь в таких партиях, за это закрывают аккаунт. Против ИИ Lichess
движок разрешён явно, разбор завершённых партий — тоже.

Запрет реализован в коде, а не надписью: приложение проверяет поле `opponent.ai`
до обращения к движку, и для живого соперника запрос к движку не создаётся вообще.
Токен запрашивается без scope `board:play`, то есть физически не может делать ходы.

## Сборка

APK собирается в GitHub Actions — локально JDK и Android SDK не нужны.

```
gh workflow run "Build APK"
gh run download --name chesscoach-debug
```

Движок не хранится в репозитории: CI собирает Stockfish с маленькой сетью из
исходников `stockfish.js` (`tools/ci/build_stockfish_lite.sh`) и кладёт его в
`app/src/main/jniLibs/arm64-v8a/libstockfish.so`.

## Обновления

Каждая сборка `main` публикуется как релиз `build-N` с файлом `chesscoach.apk`.
Приложение сравнивает свой `versionCode` с последним релизом при запуске и по кнопке
в настройках. Подпись постоянная: ключ лежит в секретах `SIGNING_KEYSTORE_BASE64` и
`SIGNING_PASSWORD`. Если потерять ключ, новые сборки не встанут поверх установленных.

## Веб-версия

https://chaplygin.github.io/chess-coach/ — разбор завершённых партий. Тот же код
`:core` и `:coach`, переведённый в JavaScript (TeaVM), и Stockfish на WebAssembly.
Собирается `tools/ci/build_site.sh` и выкладывается на GitHub Pages при сборке `main`.

## Требования к устройству

Android 12+, arm64-v8a.
