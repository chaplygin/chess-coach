## Что это

Android-приложение и сайт https://chaplygin.github.io/chess-coach/ : разбор партий Lichess с объяснениями по-русски.
Репозиторий `chaplygin/chess-coach`, публичный. Рабочая папка `D:\projects\AI_Chess`, ветка `main`, последний коммит `3d9e615`.
Ник пользователя на Lichess: `bufreg` (рапид 926, задачи 1403). Аккаунт `chaplygin` на Lichess чужой.

## Решения

Основные решения записаны в `CLAUDE.md`, их не переоткрывать. Сверх них:

- APK берём только из GitHub Actions. Скачанные кладём в `APK/`, прошлые в `APK/backup/`.
- Пороги классификации ходов как есть, зевок от 100 сантипешек. Уровень текста 1200-1800, всегда подробно, человеческий ход слабее компьютерного не больше чем на 0,5 пешки.
- Доработки копятся пулом и выпускаются вместе по команде пользователя. Перед выпуском обычно smoke-ветка, но пользователь может сказать «сразу выпускать».
- Функционал приложения и сайта одинаковый; в отчёте о релизе писать, что синхронно, а что нет.

## GitHub

- Аккаунт `litband` заблокирован GitHub (403 «Your account was suspended»). Обходить не пытаться.
- Пуш и `gh` только из вкладки терминала приложения, где вошёл `chaplygin`: `git -c credential.helper= -c "credential.helper=!gh auth git-credential" push origin main`. Сверять аккаунт: `gh api user --jq .login`.
- Инструмент PowerShell агента видит старый вход `litband`. Статус CI читать через публичный API (`curl -sk`).
- Коммит и пуш только по просьбе пользователя. Папки `backup/` и `_handoff/` не коммитить: репозиторий публичный.
- Папку `контекст/` коммитить, перед коммитом проверять на секреты (пароли, токены, ключи).

## Что проверено

- Сайт: партии `bufreg` грузятся без входа, разбор хода, итоги партии и «Мои ошибки» работают в браузере (0.2.47: разбор 7. Bxg5, экран ошибок).
- `:core`/`:coach` тесты зелёные, `:app` компилируется, `CoachReadingTest` перечитан на трёх позициях партии против Sverre-S.
- CI 47 зелёный, релиз опубликован, сайт показывает 0.2.47.

## Что не проверено

- На телефоне ничего: установка, обновление через «Проверить обновление», загрузка партий, поворот, отступы, «Разобрать N партий».
- Вход через Lichess на сайте.
- Ответ Lichess на User-Agent приложения. `/api/games/user` отвечает 404 на curl, из браузера работает. User-Agent не перебирать: классификатор блокирует это как обход защиты от ботов.
- Статические детекторы рычагов и слабых полей могут шуметь на реальных партиях.

## Окружение ПК

- JDK 17 в `D:\tools\jdk-17*`; с `JAVA_HOME` на него и `ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk` работают `gradlew.bat :core:test :coach:test :app:compileDebugKotlin --offline`. Java в `PATH` только 1.8.
- Stockfish 17.1 для `CoachReadingTest` лежал в scratchpad прошлой сессии (`sf\stockfish\stockfish-windows-x86-64-avx2.exe`); в новой сессии скачать заново через PowerShell `Invoke-WebRequest` (curl падает на SSL) и задать `CHESSCOACH_STOCKFISH`. `CHESSCOACH_ONLY_GAME` печатает только позиции партии.
- Сайт: `bash tools/ci/build_site.sh`, проверять встроенным браузером.
- Подпись: ключ в `~/.chesscoach`, копия в `D:\chesscoach-signing-backup`, менять нельзя.
