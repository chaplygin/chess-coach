# Шахматный наставник

Android-приложение и сайт https://chaplygin.github.io/chess-coach/ : разбор партий
Lichess с объяснениями по-русски. Репозиторий `chaplygin/chess-coach`, публичный.

## Решения, которые не надо переоткрывать

- Объяснения полностью офлайн, без LLM и API-ключей: текст собирается из детекторов позиции.
- Подсказок в живых партиях с людьми нет, только против ИИ Lichess и в разборе завершённых. Это фейр-плей Lichess.
- APK собирается только в GitHub Actions. Android SDK локально не ставим.
- Формат объяснения: длинный разбор тренера, уровень 1200-1800.

## Как работать

- Правки в `:core` и `:coach` сначала проверять локально: `./gradlew :core:test :coach:test` (нужен JDK 17).
- Правки текста тренера перечитывать глазами: упряжь `CoachReadingTest` запускается при заданной переменной `CHESSCOACH_STOCKFISH`.
- Сайт: `bash tools/ci/build_site.sh`, результат в `web/build/site`. Тренер там собран TeaVM из тех же модулей.
- Скачанные из CI APK класть только в `dist/`, она не отслеживается git.
- Код писать без обратных слэшей: на прежней машине они схлопывались при записи файлов (`Regex` и символы перевода строки ломались). Вместо них `split(" ")`, `appendLine()`, `String.fromCharCode(10)`.

## Обновления APK

Каждая сборка `main` публикует релиз `build-N` с файлом `chesscoach.apk`, `versionCode` равен номеру сборки CI.
Подпись постоянная, секреты `SIGNING_KEYSTORE_BASE64` и `SIGNING_PASSWORD`, ключ в `~/.chesscoach`, в репозиторий его не класть.
Без секретов сайт выкладывается, а релиз APK нет. Ставит их `bash tools/setup_signing.sh`.
После первого опубликованного релиза ключ менять нельзя: новые сборки не встанут поверх установленных.

## Ещё не проверено

- Вход через Lichess и загрузка настоящих партий на сайте: на прежней машине антивирус резал lichess.org (HTTP 499). CORS у Lichess открыт, это проверено с раннера CI.
- Скачивание и установка обновления на телефоне.
- На Lichess ник `chaplygin` вернул 404: настоящий ник пользователя может быть другим.
